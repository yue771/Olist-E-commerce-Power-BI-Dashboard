# 📊 Olist E-commerce Power BI Dashboard

## 📌 Project Overview
This project analyzes the Brazilian Olist e-commerce dataset and builds an interactive Power BI dashboard to explore sales performance, customer behavior, and product insights.

The dashboard provides business-oriented analysis including:
- GMV trends
- Order trends
- Customer analytics
- Product category performance
- RFM segmentation

---

# 🛠 Tech Stack
- Power BI
- SQL
- DAX
- Excel / CSV
- Data Visualization

---

# 📂 Dataset
Dataset: Olist Brazilian E-commerce Public Dataset

Main tables used:
- orders
- order_items
- customers
- products
- payments
- sellers

# 📊 Key Insights

## 📦 Product Performance
- Beauty & health products generated the highest GMV
- Product sales are concentrated in a few major categories

## 👥 Customer Behavior
- Most customers are one-time buyers
- Repeat customers represent a smaller but valuable segment

## 🌎 Geographic Insights
- São Paulo contributes the highest GMV
- Major Brazilian cities dominate overall sales

## 📈 Sales Trends
- Orders and GMV show clear monthly fluctuations
- Sales growth accelerated during peak periods
